## Selected Research Projects

### [UWFBench](https://github.com/zzzzineun/UWFBench)
**Associated study:** *Benchmarking Multimodal Large Language Models for Automated Clinical Reporting in Ultra-Widefield Fundus Photography: A Comparative Evaluation Study* (under review at BMJ Open Ophthalmology; presented at APOIS 2026).

Research code for benchmarking multimodal LLMs on automated clinical report generation from ultra-widefield fundus photographs. The repository includes model-inference pipelines and report-evaluation tools, including rubric-based LLM judging and scoring.

### [M.A.R.S. — Medical Record Generation Datathon](https://github.com/zzzzineun/mars)
**Grand Award (1st place) | Seoul National University Hospital, 2025**

Developed methods for reliable clinical document generation and diagnosis prediction using MIMIC-IV-Note. The project combined clinical workflow-guided *Brief Hospital Course* summarization with preference learning based on constructed omission and hallucination errors, keyword-based retrieval for factual verification, and diagnosis-focused inputs for ICD-10 code prediction. It also examined errors in generated radiology impressions against expert references.

## Collaborative Projects

### [Alice — Emergency Call Address Completion & Incident Classification](https://github.com/201803854/Alice)
**Grand Award (1st place; Minister of Science and ICT Award) | Data Youth Campus, 2023**

Built an end-to-end system for processing Korean 112 emergency calls, integrating noisy-speech recognition, named entity recognition for address extraction and completion, and incident code classification. The project included constructing Korean datasets annotated with place and business names and training task-specific models. [My fork](https://github.com/zzzzineun/ALICE).

### [YBEOBE — Korean Sentiment Analysis](https://github.com/HUFS-NLP/YBEOBE)
**Silver Award (3rd place) & KT Special Award (Innovative Idea) | Korean NLP Competition, 2023**

A collaborative project on Korean sentiment and emotion analysis for the National Institute of Korean Language's 2023 AI Language Ability Evaluation, with training, inference, and ensembling code for Korean NLP models. [My fork](https://github.com/zzzzineun/YBEOBE).
